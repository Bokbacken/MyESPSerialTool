Serial ESP Helper — leveransplan, version 0.25.1
================================================

AVGRÄNSNING
Detta repo började med enbart README och innehåller ingen ESP32-firmware,
äventyrsmotor eller karaokeuppspelare. Första leveransen är därför en
komplett vertikal etapp 1 för Windows-terminalen, inte hela önskelistan.
Version 0.25.1 gäller denna app; äldre önskemålet 0.19.3 ersätts inte i något
annat projekt.

ETAPP 1 — implementeras i denna leverans
- Qt Widgets/CMake, dynamisk Qt-distribution, Windows x64-portabel ZIP.
- Läsbar versionsmärkt INI, profiler, flera samtidiga sessionsfönster.
- Redigerbara portar/baudrate; avancerade serialinställningar och read-only.
- Portövervakning, stabil USB-identitet när tillgänglig, manuell paus.
- Inkrementell UTF-8/grundläggande ANSI, sändning, historik, lokal echo.
- Begränsad terminalvy, frikopplad mottagning/diskloggning.
- Exakta råbytes, separat metadata/textlogg, rotation och synliga loggfel.
- Abstraherad serialtransport och automatiserade tester.
- GitHub Actions-artefakter och separat explicit release med checksummor.
